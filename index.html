How it works

Scanned and redacted in the browser — before it's sent

The extension hooks the browser's own network layer, inspects each outbound prompt and file, and redacts what's sensitive. The protected version is what reaches the AI site. Nothing is ever sent to us.

What it does

Complete protection, entirely on the device

Detects secrets & PII

API keys, tokens, private keys, credit cards, IBANs, SSNs, emails, phone numbers, IPs, and your own client/project names — many checksum-validated to cut false positives.

Redact or pseudonymize

Secrets are hard-redacted and never restored. Client and project names become stable pseudonyms and are restored in the AI's reply — so the conversation stays fully usable.

Scans file uploads

Attached files are checked before they upload — text, code, CSV, JSON, config, logs, PDF, and Office documents — all parsed locally. Sensitive files prompt for confirmation.

100% local, zero-network

The detection engine is bundled in the extension. A strict content-security policy forbids remote code and the extension makes no network calls of its own. Verify it in DevTools.

Enterprise-managed

Force-install and lock settings through Google Admin, Microsoft Intune, or GPO — the tools IT already uses. No new infrastructure, no vendor console.

White-label ready

One config file rebrands the whole product — name, interface, and icon — so a partner can ship it under their own brand in minutes.

Why it's different

Built so there's nothing to send — and nothing to breach

Most DLP tools route your data through their cloud. MK Labs AI DLP has no cloud. That single decision collapses most of a security review into favorable answers.

# Content Security Policy (no eval, no remote scripts)
script-src 'self' 'wasm-unsafe-eval'
 
# Least-privilege permissions
permissions = ["offscreen", "storage"]
remote_models = false # bundled on-device
network_egress = none
